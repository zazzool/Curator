# Студия составителя

TypeScript, React, Vite. Собирается в статику, которую отдаёт сервер: один
процесс, один домен, никакого CORS и отдельной выкатки.

Разделы — только те, что обслуживают сквозной путь: источники, задачи и их
решаемость, генерация (промпты, конвейер и модели, правила, требования,
журнал обращений, расход), клиенты с отчётами и игровой механикой,
настройки студии.

Каталог пуст до своего шага — см. [docs/plan.md](../docs/plan.md).
