# Студия составителя

TypeScript, React, Vite. Собирается в статику, которую отдаёт сервер: один
процесс, один домен, никакого CORS и отдельной выкатки.

Разделы — только те, что обслуживают сквозной путь: источники, задачи и их
решаемость, генерация (промпты, конвейер и модели, правила, требования,
журнал обращений, расход), клиенты с отчётами и игровой механикой,
настройки студии.

Сейчас написан первый раздел — источники: вход по одноразовому коду,
список источников, заведение источника, загрузка документа, приёмка разбора
и срез принятого по пути. Остальные разделы приезжают по этапам —
см. [docs/plan.md](../docs/plan.md).

```bash
npm ci        # в новом рабочем дереве — до первого запуска чего бы то ни было
npm run dev   # студия своим сервером; обращения к API уходят на сервер
npm test      # проверки студии
```

В разработке студия идёт своим сервером, а обращения к редакционному API
переписываются на сервер (`CURATOR_SERVER`, по умолчанию `127.0.0.1:8080`).
Собранную статику (`npm run build`) отдаёт сам сервер: каталог называется
ему переменной `CURATOR_EDITOR_DIR`.
