# Сервер

Go. Одна программа отдаёт всё: API приложения (`/v1`), редакционное API
студии (`/admin/api`), статику студии и страницу раздачи сборки.

Устройство — пакетами по этапам сквозного пути, а не одним плоским
`package main`:

| Пакет | Этап |
|---|---|
| `internal/source` | разбор текстового источника |
| `internal/generate` | генерация задач: конвейер и подключение моделей |
| `internal/delivery` | раздача задач клиентам, пакеты, учётные записи |
| `internal/sales` | продажи, права доступа, платежи |
| `internal/analytics` | телеметрия, отчёты, решаемость, эксперименты |
| `internal/dbgate` | единственная дверь к базе |

Сейчас здесь только `schema.sql` — устройство данных. Код приезжает по
этапам, в порядке из [docs/plan.md](../docs/plan.md).
