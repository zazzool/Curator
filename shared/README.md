# Эталоны

Файлы, которые читают обе стороны — и Go, и Dart. Они существуют затем,
чтобы два расчёта одного и того же не разошлись молча: расчёт прогресса,
проводной формат ответов, канонизация подписанного манифеста.

**Отсутствие эталона роняет проверку, а не пропускает её.** Проверка,
которая молча пропускается без файла, выдаёт зелёное за непроверенное.
