# Куратор

Платформа учебных ситуационных задач. Один сквозной путь, и ничего сверх него:

**разбор текстового источника → генерация задач → раздача задач клиентам →
анализ поведения клиентов.**

Источником может быть что угодно, где есть проверяемые положения:
классификация, приказ, клинические рекомендации, стандарт, руководство.
МКБ-10 — первый из них и ничем не особеннее остальных.

## Что здесь лежит

| Каталог | Что это | Язык |
|---|---|---|
| `server/` | API приложения (`/v1`), студия составителя (`/admin/api`), генерация, доставка | Go |
| `app/` | Приложение обучающегося (Android) | Dart, Flutter |
| `web/` | Студия составителя | TypeScript, React, Vite |
| `shared/` | Эталоны, общие для сервера и приложения | JSON |
| `docs/` | Нормативные документы и план стройки | Markdown |

## Откуда это взялось

Куратор вырастает из проекта MVExams, но не переносится из него деревом.
Берутся отобранные части — конвейер генерации, подключение моделей, разбор
источников, доставка задач, игровая механика, — а всё, что к сквозному пути
не относится, не берётся вовсе. Что именно берётся, что выбрасывается и
почему — в [docs/plan.md](docs/plan.md).

Два отличия от MVExams заложены в основание, а не добавлены сверху:

- **организаций нет.** Одна установка обслуживает одного владельца, и
  изоляция арендаторов не строится: её нечему изолировать;
- **у задачи есть ссылка на единицу источника**, а не код справочника
  строкой в теле. «Раздел» и «рубрика» — срез пути, посчитанного при
  загрузке источника, а не отрезание знаков от кода.
