# Приложение

Flutter, Android. Переносится из MVExams почти целиком: практика, учётная
запись, доступ, обновление, настройки, пакеты задач с проверкой подписи,
прогресс с повторением по интервалам, знаки отличия и опыт.

Не переносятся офлайн-справочник МКБ-10 и уроки теории: Куратор — про
задачи, а не про чтение справочника.

Каталог пуст до своего шага — см. [docs/plan.md](../docs/plan.md).
