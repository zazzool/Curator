# Правила работы над Куратором

Файл читается в начале каждой сессии. Он не пересказывает устройство
проекта — для этого есть `README.md` и `docs/`. Здесь только то, что нужно
знать **каждой** сессии, чтобы не сломать работающее и не разойтись со
стилем.

Правила пришли из MVExams, где каждое из них куплено отказом. Перенесены не
все: то, что держало организации, изоляцию арендаторов и продажу через
кафедры, здесь не нужно и не переносится. Доводы у оставшихся не стёрты —
они и есть ценность.

## Что это за проект

Платформа учебных ситуационных задач. Один сквозной путь: разбор текстового
источника, генерация задач по нему, раздача задач клиентам, анализ их
поведения. Всё, что не обслуживает этот путь, в проект не входит.

**Источник любой.** Классификация, приказ, клинические рекомендации,
стандарт, руководство. МКБ-10 — обычная строка в таблице источников, а не
встроенное знание и не отдельная ветка кода. Всякий раз, когда в коде
появляется «если это МКБ», это дефект — нужно спросить у источника его
свойство, а не угадать его по формату метки.

**Организаций нет.** Одна установка — один владелец. Ни колонки владельца в
таблицах, ни политик уровня строки, ни выбора арендатора по домену. Это
решение, а не упущение: изоляция, которой нечего изолировать, стоит дорого
и ошибается молча.

## Обязательные проверки

Перед тем как объявить работу сделанной, прогоняются наборы сервера,
приложения и студии. Красный набор означает, что работа не сделана.

```bash
./tools/checks.sh
```

Статические проверки стоят секунды и ловят неотправляемое:

```bash
cd server && gofmt -l . && go vet ./...
cd app    && dart format --output=none --set-exit-if-changed lib test && flutter analyze
cd web    && npm run typecheck
```

**Проверки на живой базе не пропускаются молча.** Набор, тихо
пропускающий проверки SQL без строки подключения, хуже отсутствия набора:
он выдаёт зелёное за непроверенное. Число таких проверок стережётся одним
местом, и переписывать его во второе нельзя — два места для одного числа
расходятся молча.

## Стиль

**Комментарий объясняет «почему», а не «что».** Код и так показывает, что
он делает. Ценность комментария — в причине: какой отказ он предотвращает,
какой случай уже был, почему очевидное решение не подошло.

**Обоснования не стираются при правках.** Переносишь код — переноси и
объяснение. Перестало быть верным — исправь, а не удаляй.

**Русский язык в комментариях, сообщениях об ошибках и интерфейсе.**
Идентификаторы английские. Тексты, которые видит человек, пишутся так, будто
их читает врач, а не программист.

**Пиши как окружающий код.** Плотность комментариев, длина функций, порядок
объявлений уже заданы; новый файл не должен выделяться.

## Что нельзя ломать

**Общий эталон расчёта прогресса.** Один файл читают и Go, и Dart. Расчёт
опыта, уровней и величин обязан сходиться. При отсутствии файла проверки
падают, а не пропускаются.

**Зеркальность словарей.** Словарь событий телеметрии, каталог величин и
каталог знаков отличия существуют одновременно в сервере и приложении.
Проверки сервера читают исходники приложения и сверяют построчно. Менять
можно только парой, и сверка обязана отказывать, а не пропускать: сверка,
зовущая «пропустить» на недоступном исходнике, не сверяет ничего.

**Знаки отличия выдаёт сервер, а не устройство.** Номер, дата выдачи, тираж
и доля обладателей — сведения о том, каким врач пришёл среди всех, и из его
собственной истории они не выводятся. Опыт начисляется по **выданному**:
знак с тиражом можно заслужить и не получить.

**Выданный знак не отбирают.** Строка о выдаче не удаляется никогда.
Переходящий знак получает отметку об отзыве, а не удаление, потому что
собирательные знаки смотрят на когда-либо выданное.

**Слепая сверка остаётся слепой.** Проверке уходит только текст условия — ни
метки источника, ни названия, ни положений. Подскажи модели хоть чем-нибудь,
и проверка выродится в самоподтверждение.

**Списки не отдаются пустым значением.** Пустой список — `[]`, а не `null`.
Ошибка ломает только исправные случаи: у задачи без замечаний список
замечаний пуст, и редактор падает белым экраном именно на хороших задачах.

**Непонятое не применяется.** Чужая версия схемы, испорченный конфиг,
негодное правило, битая задача в пакете отбрасываются целиком — не роняя
остального и не подменяя данные умолчаниями молча.

**Совпадение двух реализаций.** Где правило написано и на Go, и на SQL,
проверки на настоящей базе сверяют их поле за полем: расходятся такие пары
молча.

**Обратная совместимость с установленными приложениями.** Проводные форматы
меняются только добавлением необязательных полей; смысл существующего поля
не меняется никогда. Стережёт это записанный эталон ответов —
`shared/wire-contract.json`; отсутствие файла роняет проверку, а не
пропускает её. Правило начинает действовать с первой сборки на руках у
врача — до неё формат правится свободно, и это единственное окно. Сейчас
оно открыто, и так и записано в самом эталоне (`"window": "open"`).

С другой стороны провода — то же самое: **лишние поля в запросе к `/v1` не
отказ.** Новая сборка, пославшая поле, которого старый сервер не знает,
обязана работать. Этим `/v1` отличается от редакционного API, где лишнее
поле — отказ: студия и сервер выкатываются вместе, приложение — нет.

**Единственная дверь к базе.** Пул спрятан за шлюзом и наружу не выдаётся:
пройти мимо должно быть невозможно, а не нежелательно.

**Маршрута без права не бывает.** Право стоит первым доводом при объявлении
каждого маршрута студии — этого не даёт забыть компилятор. Разделы студии
закрыты правом, а не спрятаны в интерфейсе: скрытый раздел — подсказка, где
искать, а не запрет.

**Схема базы растёт только добавлением.** Все `ALTER` идемпотентны, все
`INSERT` — с `ON CONFLICT DO NOTHING`. Накат применяется до подмены кода:
код, вышедший раньше своей схемы, падает не при старте, а на первом
обращении к недостающей колонке — то есть у врача, а не в журнале выкатки.

**Две валюты не смешиваются.** Расход на модели считается в долларах
(нанодолларами, целым числом), выручка и цены пакетов — в рублях
(копейками). Перевод делается при показе, по курсу на день показа, и
остаётся видимым как перевод. Записанный в строку курс дня потерян
безвозвратно, и сумма за месяц после этого не сходится ни с чьим счётом —
ни с долларовым счётом поставщика, ни с нашим рублёвым.

**Оценка не выдаётся за факт.** Цену обращения к модели называет
маршрутизатор; остальным шлюзам её считают по прайсу и помечают как
оценку. Расчёт не знает ни скидки префиксного кэша, ни наценки шлюза и
ошибается в разы там, где кэш работает. Число, которое выглядит точным и
таковым не является, хуже отсутствия числа.

**Право на доступ отвязано от способа оплаты.** Право выдаётся платежом,
живёт само и проверяется одинаково, чем бы ни было куплено. Два учёта,
склеенные задним числом, — это миграция по живым деньгам.

**Эквайер включается только после сверки подписи.** Сперва секрет и проверка
подписи уведомления, и только потом включение приёма платежей. Настройка,
включённая раньше подписи, открывает всякому желающему ручку, которая
оформляет права.

## Ловушки, на которые уже наступали

**`head -1 | grep -q` под `set -o pipefail`.** `grep` закрывает канал на
первом совпадении, писатель получает SIGPIPE, и исправная проверка
возвращает отказ. Читай строку в переменную, а не через конвейер.

**Присваивание из подстановки команд под `set -e`.** Строка `x=$(… | grep …)`
при отсутствии совпадения убивает скрипт на самой себе, и написанный следом
`|| die "внятное сообщение"` не выполняется никогда.

**`gofmt -l .` на копии с CRLF** перечисляет почти все файлы. Переводы строк
здесь принудительно LF; не «исправляй» их обратно.

**Свой прогон проверок рядом с выкаткой врёт.** Признак подделки простой:
файл упал, а ни одна проверка не упала — это сборка, а не работа.

## Чего не делать

- **Не добавлять зависимости без нужды.** Нужда называется вслух, в
  комментарии рядом с зависимостью: что именно нельзя сделать без неё.
- **Не браться за разбор PDF.** Перевод PDF в текст делает служба снаружи.
  Принимаются текст, Markdown и DOCX. Это выбранная граница, а не очередь
  работ, и отказ по PDF не должен обещать «позже».
- **Не вводить тени в интерфейсе** — плоскости разделяются волосяной
  границей. Тень допустима только у того, что физически висит над страницей.
- **Не открывать закрытые словари «для гибкости»:** их закрытость и есть то,
  что делает контракты дешёвыми.
- **Не заводить вторую реализацию расчёта прогресса.** Их и так две, и
  сходятся они только благодаря общему эталону.
- **Не вписывать адрес контура литералом.** Для этого есть одно место.
