# Знаки отличия

Знак — это отметка о том, каким врач пришёл **среди всех**: номер, дата
выдачи, тираж, доля обладателей. Поэтому знак выдаёт сервер, и только он.

Устройство считает по общему каталогу ровно одно — долю пути к знаку: её
видно и без сети, и в ней нет ничего о других.

Каталог живёт в `shared/signs-catalog.json`, и его читают обе стороны. Два
каталога, набранных порознь, расходятся молча, и первым это увидит врач, у
которого на экране знак называется иначе, чем в свидетельстве. Отсутствие
файла роняет проверку, а не пропускает её.

## Виды знаков

Словарь закрыт: вид, заведённый по месту, приложение не нарисует, а сервер
выдаст — и знак повиснет невидимым.

| Вид | За что |
|---|---|
| `metric` | за величину, тираж не ограничен |
| `edition` | за величину, но тиражом: заслужить можно и не получить |
| `collective` | за уже выданные знаки |
| `rotating` | переходящий: держит его один, лучший по величине |

## Что выдано

```bash
curl -s "$СЕРВЕР/v1/signs" -H "Authorization: Bearer $ТОКЕН"
```

```json
{"signs": [
  {"slug": "first-steps", "title": "Первые шаги", "kind": "metric",
   "issued": true, "progress": 1, "serial": 41,
   "issuedAt": "2026-09-19T10:00:00Z", "revoked": false,
   "issuedCount": 41, "editionSize": 0, "holdersShare": 0.62},
  {"slug": "hundred", "title": "Сотня", "kind": "metric",
   "issued": false, "progress": 0.34, "serial": 0,
   "issuedAt": "", "revoked": false,
   "issuedCount": 3, "editionSize": 0, "holdersShare": 0.04}
]}
```

**Каталог отдаётся целиком, вместе с невыданными.** Знак, о котором врач не
знает, не мотивирует никого.

`editionSize` ноль значит «тираж не ограничен». `issuedAt` у невыданного —
пустая строка, а не `null`: приложение показывает её как есть.

## Как выдаётся

Знаки выдаются в тот же миг, что и приходят разборы, **в одной транзакции с
ними**. Разорви эти два действия — и обрыв между ними оставит либо знак без
величины, которая его объясняет, либо величину без знака, который по ней
положен.

Знаки, выданные пачкой, приезжают ответом на неё:

```json
{"accepted": 3, "xp": 510, "level": 4,
 "signs": [{"slug": "hundred", "title": "Сотня", "serial": 4, "xp": 200}]}
```

Это событие, и показывать его надо сразу: знак, о котором врач узнал бы при
следующем заходе в раздел наград, не награда, а находка.

**Номер выдаёт база под замком строки**, а не счётчик в коде. Два
соперника, посчитавшие «следующий номер» по одному и тому же состоянию,
выдали бы один номер двоим, и поймал бы это только указатель уникальности —
уже на записи, отказом посреди пачки.

## Опыт начисляется по выданному, а не по заслуженному

Знак с тиражом можно заслужить и не получить: тираж кончился, а величина
достигнута. Расчёт «по заслугам» показал бы врачу опыт за знак, которого у
него нет, и объяснить это было бы нечем.

Кончившийся тираж — не отказ: разбор принимается, опыт за верный ответ
начисляется, просто знака нет.

## Выданный знак не отбирают

Строка о выдаче **не удаляется никогда**. Единственное исключение —
переходящий знак: он получает отметку об отзыве, а не удаление.

Причина не в бережливости. Собирательные знаки смотрят на **когда-либо
выданное**: считай они владение сейчас, кавалерский знак Ордена Точности
срывался бы вслед за переходящим, и собрать орден было бы нельзя в
принципе.

По той же причине и доля собранного ордена считается по когда-либо
выданным частям: иначе врач видел бы, как собранное разбирается обратно.

## Переходящий знак

Переходит он строго по «больше», а не «не меньше». На равенстве знак
дёргался бы между двумя врачами при каждой пачке, и свидетельство о нём
ничего бы не значило.

Прежний обладатель остаётся в списке с отметкой `revoked`. Знак у него был,
и это правда, которую незачем стирать.

## Выпуски заводятся по каталогу

При старте сервер заводит выпуски знаков по каталогу: каталог остаётся
единственным местом, где знак объявлен, а строки в базе — следом выдачи, а
не вторым объявлением.

**Тираж не уменьшается задним числом.** Уменьшить его ниже уже выданного
значит объявить часть знаков несуществующими — а выданный знак не
отбирают. Такая правка роняет старт, а не проходит молча.
