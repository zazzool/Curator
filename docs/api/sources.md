# Редакционное API: источники

Первый этап сквозного пути целиком, без студии. Всё, что ниже, можно пройти
из командной строки — так этап и проверяется, пока экран не написан.

Адрес контура берётся из настроек, а не вписывается здесь литералом; в
примерах он назван переменной.

```bash
СТУДИЯ=http://127.0.0.1:8080
```

## Дверь

Вход по имени и одноразовому коду; код даёт программа-аутентификатор,
заведённая вместе с пользователем студии.

```bash
ТОКЕН=$(curl -s -X POST "$СТУДИЯ/admin/api/login" \
  -H 'Content-Type: application/json' \
  -d '{"login":"составитель","code":"123456"}' | jq -r .token)

curl -s "$СТУДИЯ/admin/api/me" -H "Authorization: Bearer $ТОКЕН"
```

Дальше токен идёт в каждом обращении. Без него ручка отвечает «Войдите в
студию заново», а не пустотой: пустоту работа принимает за правду.

## Права

| Ручка | Право |
|---|---|
| Чтение источников, единиц, положений, кусков и черновика | `source:read` |
| Заведение источника, загрузка документа, черновик, приёмка | `source:accept` |

Читать источник и принимать разбор — разные права намеренно: принять разбор
значит решить, что теперь считается истиной источника.

## Завести источник

Четыре свойства обязательны и умолчаний не имеют: вид, ось, смысл
вложенности и полнота. Ось — по чему источник делит материал; по ней подбор
решает, складываются ли два источника в один список или стоят поперёк друг
друга. Полнота честна: разобранный из DOCX кусок — это `fragment`, и
объявлять его полным нельзя, на полноту опирается расчёт охвата.

```bash
curl -s -X POST "$СТУДИЯ/admin/api/sources" \
  -H "Authorization: Bearer $ТОКЕН" -H 'Content-Type: application/json' \
  -d '{"slug":"prikaz-1130n","kind":"decree","title":"Приказ № 1130н",
       "unitWord":"пункт","statementWord":"положение",
       "purpose":"legal","hierarchy":"part-of","completeness":"fragment"}'
```

Словари закрыты: `kind` — `classification | decree | guidelines | standard |
handbook | other`, `purpose` — `topic | system | discipline | task | level |
legal | other`, `hierarchy` — `is-a | part-of | grouped`, `completeness` —
`complete | fragment`.

## Принести документ

Принимаются текст, Markdown и DOCX. PDF не принимается — это выбранная
граница проекта: перевод PDF в текст делает служба снаружи.

```bash
curl -s -X POST "$СТУДИЯ/admin/api/sources/1/documents" \
  -H "Authorization: Bearer $ТОКЕН" -F file=@prikaz.docx
```

Документ режется на куски сразу при загрузке, а не по отдельной команде:
лежащий неразобранным документ выглядит загруженным и молча не работает.
Ответ говорит номер документа, узнанный формат и число кусков; сами куски —
`GET /admin/api/documents/{id}/fragments`.

Один и тот же файл, принесённый дважды, — один документ: повтор узнаётся по
отпечатку и возвращает прежний номер.

## Черновик и приёмка

Черновик разбора кладётся целиком, заменяя прежний: это один ответ на один
документ, и склейка двух ответов даёт разбор, которого не делал никто. Пока
генерация не приехала, черновик кладут этой ручкой руками.

```bash
curl -s -X PUT "$СТУДИЯ/admin/api/documents/5/draft" \
  -H "Authorization: Bearer $ТОКЕН" -H 'Content-Type: application/json' \
  -d '{"units":[{"label":"3","parentLabel":"","title":"Порядок"},
                {"label":"3.2","parentLabel":"3","title":"Сроки"}],
       "statements":[{"unitLabel":"3.2","kind":"обязанность",
                      "designation":"абз. 1","placeRef":"с. 4",
                      "body":"Срок рассмотрения — десять рабочих дней."}]}'

curl -s -X POST "$СТУДИЯ/admin/api/documents/5/accept" \
  -H "Authorization: Bearer $ТОКЕН"
```

Приёмка — одна транзакция: либо приняты все единицы, либо ни одной.
Источник с половиной принятой ветки хуже непринятого — у части единиц путь
есть, у части нет, и срез отдаёт то одно, то другое. Потерянный родитель,
петля и повтор метки роняют приёмку целиком, а не тихо выбрасывают строку.

Приёмку можно повторить: единицы обновятся, положения принятых единиц
заменятся, а не лягут вторым слоем.

## Срез по пути

Путь считается при приёмке из связи с родителем (`3/3.2`), а не отрезанием
знаков от метки. Отсюда срез: «всё, что под пунктом 3» — один запрос.

```bash
curl -s "$СТУДИЯ/admin/api/sources/1/units?path=3" -H "Authorization: Bearer $ТОКЕН"
curl -s "$СТУДИЯ/admin/api/sources/1/statements?unit=3.2" -H "Authorization: Bearer $ТОКЕН"
```

Для МКБ-10 результат тот же, что дало бы отрезание знаков от кода, но
получен он данными, а не догадкой о формате метки. В этом и смысл: «если это
МКБ» в коде не появляется.

Пустой список приезжает как `[]`, а не `null`, — и это не мелочь: `null`
роняет студию белым экраном именно на исправном случае, на источнике, куда
ещё ничего не принято.
